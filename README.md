# Belara — Landing Page de Arquitetura

Projeto acadêmico de front-end inspirado em um layout de arquitetura, desenvolvido para praticar construção de páginas com **HTML e CSS**.

## Tecnologias

- HTML5
- CSS3

## O que o projeto pratica

- estruturação de seções;
- hero e navegação;
- uso de imagens e assets;
- composição visual;
- estados de hover;
- organização de conteúdo em uma landing page.

## Responsividade

O projeto está passando por revisão para melhorar a adaptação a notebooks, tablets e celulares, reduzindo dependência de posicionamentos fixos e tornando imagens e seções mais flexíveis.

## Como executar

1. Clone o repositório.
2. Abra `index.html` no navegador.

## Contexto

Projeto criado durante a formação técnica em TI como exercício de desenvolvimento web e reprodução de layout.
